# 🧹 Data Cleaner & Report Tool

أداة بايثون بسيطة لأتمتة تنظيف البيانات وتوليد تقرير جودة سريع لأي ملف Excel أو CSV.

## المشكلة
تنظيف البيانات (حذف التكرار، معالجة القيم الفارغة، توحيد التنسيق) خطوة تتكرر يدويًا في كل مشروع تحليل بيانات — هذي الأداة تؤتمتها بأمر واحد.

## المميزات
- قراءة ملفات CSV و Excel
- حذف الصفوف المكررة تلقائيًا
- معالجة القيم الفارغة (متوسط للأعمدة الرقمية، تصنيف افتراضي للنصية)
- توحيد صيغة أعمدة التاريخ
- إزالة المسافات الزائدة من النصوص
- تصدير:
  - ملف بيانات نظيف (`.xlsx`)
  - تقرير جودة بيانات متعدد الشيتات (ملخص عام، القيم الفارغة لكل عمود، وصف إحصائي)

## طريقة الاستخدام

```bash
pip install pandas openpyxl
python cleaner.py my_file.csv
```

النتيجة: ملفين جديدين بجانب ملفك الأصلي — نسخة نظيفة، وتقرير تفصيلي.

## مثال
ملف مدخل فيه بيانات فوضى (تكرار، فراغات، تنسيق تاريخ مختلط) →
- تقرير يبين: عدد الصفوف المكررة، عدد القيم الفارغة لكل عمود
- ملف نظيف جاهز للتحليل مباشرة

## التقنيات المستخدمة
- Python
- pandas
- openpyxl

## عن المشروع
صممت هذي الأداة لأتمتة خطوة تنظيف وتحضير البيانات اللي عادة تاخذ وقت طويل يدويًا في Power Query أو Excel. الهدف إنها توفر أول خطوة سريعة وموثوقة قبل أي تحليل، وتقلل الأخطاء البشرية بالتنظيف اليدوي.
